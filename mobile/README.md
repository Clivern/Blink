# Blink Mobile App

React Native mobile app built with [Expo](https://expo.dev).

## Prerequisites

- Node.js (see `.nvmrc` if present)
- The Expo CLI runs via `npx`, no global install needed.

## Run

```bash
cd mobile
npm install
npm start
```

Then scan the QR code with Expo Go, or press `a` / `i` for an
Android emulator / iOS simulator, or `w` to run in the browser.
